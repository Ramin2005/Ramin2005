## 👋 About Me

I'm a **Computer Engineering student at Kharazmi University**, interested in understanding and building computer systems from the hardware level up.

My main interests lie in **digital logic, RTL design, computer architecture, embedded systems, algorithms, and mathematics**. I enjoy turning theoretical concepts into practical implementations — whether that means designing a datapath, implementing a hardware module, or experimenting with a microcontroller.

- 🔭 Currently developing my knowledge of **RISC-V processor architecture and VHDL-based RTL design**.
- 🧩 Interested in how processors, memory systems, and digital components work together.
- ⚙️ Exploring embedded systems, FPGA design, and hardware-oriented problem solving.
- 📚 Always learning, experimenting, and improving through hands-on projects.

## 🚀 Featured Projects

### [RISC-V CPU](https://github.com/Ramin2005/RISC-V-CPU)
**Processor architecture experiments using VHDL**

A hardware-design project focused on RISC-V processor components and datapath organization. The repository includes RTL modules such as an ALU, control logic, immediate generator, register file, program counter, and multiplexers, with work organized around RV64 and RV64IM designs.

**VHDL** · **RISC-V** · **Computer Architecture** · **RTL Design**

### [VHDL Learning](https://github.com/Ramin2005/VHDL-Learning)
**A growing collection of digital-design building blocks**

An educational RTL collection covering combinational and sequential circuits, including decoders, multiplexers, priority encoders, arithmetic units, ALUs, registers, counters, and generic hardware components.

**VHDL** · **Digital Logic** · **Combinational Logic** · **Sequential Logic**
