## ⚙️ Engineering Focus

My work and learning revolve around the design and implementation of computer systems, with an emphasis on:

- **Computer Architecture:** RISC-V ISA, datapaths, control units, ALUs, memory systems, and processor organization.
- **Digital Design & RTL:** VHDL, combinational and sequential logic, reusable hardware components, and synthesizable designs.
- **Algorithms & Mathematics:** data structures, discrete mathematics, combinatorics, and problem solving.

## 🚀 Featured Projects

### [RISC-V CPU](https://github.com/Ramin2005/RISC-V-CPU)
**VHDL · RV64 · RV64IM · Processor Design**

A processor-design project built from modular RTL components. The repository contains implementation work for key parts of a RISC-V datapath and its control path.

**Main components**
- Arithmetic Logic Unit (ALU)
- Main Control and ALU Control
- Immediate Generator (ImmGen)
- Register File
- Program Counter
- Adders and multiplexers

[Explore the repository →](https://github.com/Ramin2005/RISC-V-CPU)

### [VHDL Learning](https://github.com/Ramin2005/VHDL-Learning)
**VHDL · Digital Logic · RTL Components**

A collection of VHDL implementations and experiments covering fundamental digital-design building blocks. The goal is to develop a reusable understanding of hardware description, logic design, and synthesis-oriented coding.

**Topics**
- Combinational circuits
- Sequential circuits and registers
- Decoders and multiplexers
- Arithmetic units and ALUs
- Counters and other digital components

[Explore the repository →](https://github.com/Ramin2005/VHDL-Learning)
